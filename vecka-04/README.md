###Kapiter 3 - IP-adresser och subnätning

#Syfte med kapitlet

1. Räkna ut nätadress, broadcast, antal användbara adresser och adressintervall
för ett givet nät.  
2. Sätta en statisk IP-adress på en PC och på ett router-interface.  
3. Förklara vad default gateway gör och vad som händer utan den.  
4. Konfigurera en DHCP-pool på en 2951 och verifiera att en klient får adress.  
5. Skilja ett DNS-problem från ett DHCP-problem.
